# Security policy

Report a vulnerability privately through GitHub's "Report a
vulnerability" button on this repository's Security tab. Please do not
open a public issue for it. You will get a reply within 7 days.

Scope: the code in this repository. The manifest checker is a teaching
tool run on scripted fixtures; it has not been hardened for untrusted
manifest files, and the Go and Rust sources have never been compiled.
Do not use either as a security control.
